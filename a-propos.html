À propos de Dictum

Dictum est un logiciel de dictée vocale édité par BREIZHZION, association d'intérêt général à Villeurbanne. Il est né d'un besoin simple : dicter du texte sans qu'un service distant reçoive une copie de tout ce qu'on prononce.

La promesse, et ce qui la rend vérifiable

La reconnaissance vocale s'exécute sur la machine de l'utilisateur. Il n'y a pas de compte, pas de clé d'API, pas de quota, et aucune requête réseau nécessaire pour transcrire. Ce n'est pas une politique de confidentialité qui le promet : c'est une conséquence de la façon dont le logiciel est construit, et le moyen le plus direct de s'en convaincre est de couper le réseau et de continuer à dicter.

Les seules connexions que Dictum établit sont celles que l'utilisateur déclenche lui-même : télécharger un modèle de reconnaissance vocale, ou télécharger un moteur accéléré pour carte graphique. Chaque fichier reçu est vérifié par son empreinte avant d'être utilisé.

Le code

Le code source est public sur github.com/bzhzion/dictum-desktop, sous licence BZ-1.1. C'est une licence en accès libre, pas une licence open source au sens de l'OSI : l'usage personnel par une personne physique est autorisé, l'usage commercial et la prestation pour un tiers sont réservés à l'association. Le texte complet, en français et en anglais, est dans le dépôt.

Le logiciel est écrit en Rust. La reconnaissance vocale repose sur whisper.cpp et sur les modèles Whisper d'OpenAI, tous deux sous licence MIT, reproduite dans le fichier NOTICE.md du dépôt. Ces composants restent sous leur propre licence, que la nôtre ne recouvre pas.

Une réécriture complète

Une première version de Dictum a existé jusqu'à une v1.7 en juin 2026. Elle a été reprise de zéro en septembre 2026, et la version actuelle ne partage aucun code avec elle. Le motif était mesuré plutôt que ressenti : plus de sept mille lignes livrées sur sept versions mineures, sans un seul test automatisé et sans aucune vérification qui compile le projet.

La conséquence assumée est qu'il n'y a aucune compatibilité entre les deux. Les réglages, l'historique et les modèles de l'ancienne version ne sont pas repris, et la version actuelle fait volontairement moins de choses. La liste de la page d'accueil décrit ce qui existe, pas ce qui est prévu.

Ce qui n'existe pas encore

Sous Linux, la dictée fonctionne sur une session X11 ; sur Wayland, le raccourci global et l'écriture dans l'application active ne sont pas encore pris en charge. Sur macOS, le logiciel se compile mais la dictée n'est pas disponible. Ces manques sont dans cet ordre de priorité, et ils sont écrits ici pour que personne ne les découvre après l'installation.

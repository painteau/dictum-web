Détails techniques

Cette page est pour les personnes qui veulent savoir ce que le logiciel fait exactement, et pour celles qui installent Dictum sur une machine Linux. La page d'accueil suffit pour s'en servir.

Ce qui tourne réellement

La reconnaissance vocale est assurée par whisper.cpp, exécuté en local, avec les modèles Whisper d'OpenAI. Le logiciel est écrit en Rust, l'interface en Tauri. Aucune requête réseau n'est nécessaire pour transcrire : les seules connexions que Dictum établit sont celles que l'utilisateur déclenche, pour télécharger un modèle ou un moteur accéléré, et chaque fichier reçu est vérifié par son empreinte SHA-256 avant d'être utilisé.

Les trois moteurs

Le moteur processeur est embarqué dans l'installateur Windows : on peut dicter dès la fin de l'installation, sans rien télécharger d'autre. C'est délibéré, et c'est le seul moteur dont le logiciel ne peut pas se passer : si le catalogue distant est injoignable, on perd la vitesse, jamais la capacité à dicter.

MoteurPoidsMatérielGain mesuré
Processeurinclusn'importe lequelréférence
Vulkan21 MoAMD, Intel, NVIDIA×3,4 sur une carte d'entrée de gamme déjà ancienne
CUDAplus de 600 MoNVIDIA seulementenviron 15 % de plus que Vulkan

Le moteur CUDA n'est proposé que si un pilote NVIDIA est détecté sur la machine : faire télécharger 600 Mo pour un moteur qui refusera de démarrer serait une mauvaise façon de découvrir qu'on n'a pas la bonne carte. Au vu du rapport entre les deux, Vulkan est le bon choix dans presque tous les cas.

Installer sous Debian ou Ubuntu

Dictum est publié sur le dépôt apt de l'association. L'ajouter une fois suffit : les versions suivantes arrivent avec les mises à jour habituelles du système.

curl -fsSL https://apt.breizhzion.com/KEY.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/breizhzion.gpg

echo "deb [signed-by=/usr/share/keyrings/breizhzion.gpg] \
https://apt.breizhzion.com stable main" \
  | sudo tee /etc/apt/sources.list.d/breizhzion.list

sudo apt update && sudo apt install dictum

Le paquet déclare ses dépendances, elles s'installent avec lui. Pour un téléchargement direct sans ajouter de dépôt, le paquet seul est disponible ici.

Installer sous Arch

Dépôt pacman de l'association, paquets signés.

printf '\n[breizhzion]\nSigLevel = Required DatabaseRequired\nServer = https://pacman.breizhzion.com/$arch\n' \
  | sudo tee -a /etc/pacman.conf

curl -fsSL https://pacman.breizhzion.com/KEY.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key apt@breizhzion.com

sudo pacman -Syu dictum-bin

Bien -Syu et non -Sy : synchroniser la base puis n'installer qu'un seul paquet est le motif de mise à jour partielle contre lequel Arch met explicitement en garde.

Ce que le logiciel ne fait pas

  • Wayland n'est pas pris en charge : le raccourci global et l'écriture dans la fenêtre active demandent des mécanismes différents de ceux de X11, et ils ne sont pas encore écrits.
  • macOS se compile et un binaire est publié, mais la dictée n'y fonctionne pas : c'est le système qui demande le plus de travail spécifique, et il est explicitement remis à plus tard.
  • Pas de transcription en continu, pas de reformulation par un modèle de langue, pas d'interface en ligne de commande étendue, pas d'extension d'éditeur. Une version antérieure et abandonnée du projet en avait ; la version actuelle est repartie de zéro et fait volontairement moins.

Où sont vos dictées sur le disque

L'historique des dictées, les réglages et les modèles téléchargés vivent dans votre profil utilisateur, sous l'identifiant org.breizhzion.dictum.desktop, et jamais dans le répertoire d'installation :

SystèmeEmplacement
Windows%LOCALAPPDATA%\org.breizhzion.dictum.desktop
Linux$XDG_DATA_HOME/org.breizhzion.dictum.desktop, sinon ~/.local/share/...
macOS~/Library/Application Support/org.breizhzion.dictum.desktop

C'est le seul endroit où le texte de vos dictées existe. Supprimer ce répertoire les supprime définitivement, et régler l'historique à zéro dans les réglages fait que rien n'y est écrit au départ.
